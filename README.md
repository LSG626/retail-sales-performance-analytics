# Retail Sales Performance Analytics

An end-to-end Data Analytics project that transforms raw multi-sheet retail transaction data into a cleaned analytical dataset, stores it in MySQL, performs business-focused SQL analysis, and presents the results through an interactive Power BI dashboard.

This project was created as **Day 1 of my 30-Day Machine Learning & Data Analytics Portfolio Challenge**.

---

## Project Overview

Retail businesses generate large volumes of transactional data every day, but raw transaction records alone do not provide useful business insights.

The purpose of this project is to transform retail transaction data into meaningful information that can help management understand:

- Revenue performance
- Customer purchasing behaviour
- Product performance
- Geographic sales performance
- Order patterns
- Customer value
- Returns and cancellations
- Seasonal trends
- Sales performance over time

The project follows a complete analytics workflow:

```text
Raw Excel / CSV Files
        ↓
Python Data Ingestion
        ↓
Multiple Excel Sheets Combined
        ↓
Data Cleaning & Feature Engineering
        ↓
Processed Dataset
        ↓
MySQL Database
        ↓
SQL Business Analysis
        ↓
Power BI Dashboard
        ↓
Business Insights & Recommendations
